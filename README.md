# مسار MASAR — منصة المحاكاة المالية وذكاء القرار ومرشد الأعمال الذكي

**الإصدار:** 2.0  
**المنصات:** Android (Jetpack Compose / Kotlin)  
**اللغة الأساسية:** العربية RTL (مع دعم الأرقام والمصطلحات الإنجليزية)  
**الحالة:** Production Ready Commercial Application Architecture  

---

## وثيقة المتطلبات والمواصفات الكاملة للمشروع

```markdown
مسار MASAR منصة المحاكاة المالية وذكاء القرار ومرشد الأعمال الذكي 

الإصدار: 2.0
المنصات: Android + iOS
اللغة الأساسية: العربية RTL
اللغات المستقبلية: قابلة للتوسع
Frontend: React Native + TypeScript / Native Android (Jetpack Compose)
Backend / BaaS: Appwrite / Local Encrypted Room DB
AI: LLM API عبر Backend آمن، مع تصميم قابل لدعم Gemini أو OpenAI أو مزود آخر
الحالة المطلوبة عند التسليم: Production Ready Commercial Application

1. الرؤية العامة 

"مسار" ليس تطبيق تسجيل مصروفات تقليديًا، وليس مجرد Chatbot مالي.

"مسار" هو منصة ذكاء قرار مالي وتجاري تساعد المستخدم على فهم وضعه الحالي، استكشاف مستقبله المحتمل، تجربة القرارات قبل تنفيذها، مقارنة البدائل، اكتشاف المخاطر، ومعرفة أفضل الخيارات المتاحة بناءً على بياناته وأهدافه.

الفكرة الجوهرية:

لا يخبر المستخدم فقط بما حدث لأمواله، بل يساعده على معرفة ما قد يحدث إذا اتخذ قرارًا معينًا، وما البدائل المتاحة، وما الإيجابيات والسلبيات والمخاطر والحلول المحتملة.

2. الوظائف الجوهرية للمنتج 

يجب أن يجمع النظام بين خمس طبقات رئيسية:

2.1 Financial Data Layer 
جمع البيانات المالية للمستخدم مثل:
رأس المال. الدخل. المصروفات. الإيرادات المتكررة. الالتزامات. الديون. الأصول. الأهداف. الميزانيات. المعاملات. 

2.2 Financial Engine 
محرك حساب مالي deterministic مستقل عن الذكاء الاصطناعي.
مسؤوليته:
Cash Balance. Revenue. Expenses. Net Cash Flow. Burn Rate. Runway. Forecast. Break-even. ROI عندما ينطبق. Payback Period عندما ينطبق. Scenario calculations. Valuation calculations. Risk calculations. 

2.3 Scenario Engine 
محرك محاكاة يسمح للمستخدم بتجربة:
ماذا لو؟
ومقارنة السيناريوهات المستقبلية.

2.4 Decision Intelligence Engine 
طبقة مسؤولة عن تحليل القرار وليس مجرد حسابه.
يجب أن تستطيع:
تحديد الإيجابيات. تحديد السلبيات. تحديد المخاطر. تحديد نقاط القوة. تحديد نقاط الضعف. اكتشاف الفرص. اكتشاف التهديدات. اقتراح حلول. اقتراح بدائل. مقارنة البدائل. تحديد الخيار الأكثر ملاءمة وفق أهداف المستخدم. تفسير سبب التوصية. عرض الحالات المتفائلة والمتوسطة والمتشائمة. عرض مستوى الثقة. توضيح الافتراضات التي أدت إلى النتيجة. 

2.5 AI Advisor 
طبقة الذكاء الاصطناعي التي:
تشرح النتائج. تجيب عن الأسئلة. تحلل البيانات. تقدم توصيات. تقترح استراتيجيات. تساعد المستخدم على اكتشاف فرص جديدة. تتفاعل مع نتائج Financial Engine وDecision Engine. 

3. قاعدة معمارية أساسية 
ممنوع جعل الذكاء الاصطناعي مسؤولًا عن الحساب المالي الأساسي.
التدفق:
User Data ↓ Financial Data Layer ↓ Financial Engine ↓ Scenario Engine ↓ Decision Intelligence Engine ↓ AI Orchestrator ↓ LLM Provider ↓ Validated AI Response ↓ User 

4. مبادئ المنتج 
يجب أن يكون مسار: مفيدًا، واضحًا، سريعًا، موثوقًا، قابلًا للتفسير، آمنًا، قابلًا للتوسع، غير مضلل، لا يعطي ثقة زائفة في التوقعات.

5. الفئة المستهدفة
المستقلون، أصحاب المشاريع الصغيرة، رواد الأعمال، أصحاب المتاجر الإلكترونية، أصحاب SaaS، أصحاب المنتجات الرقمية، مقدمو الخدمات، المستشارون، أصحاب الأصول.

6. الرحلة الكاملة للمستخدم
Splash ↓ Onboarding ↓ Business Setup ↓ Financial Setup ↓ First Financial Analysis ↓ Dashboard ↓ Transactions / Assets / Goals ↓ Simulation ↓ Decision Analysis ↓ AI Advisor ↓ Action / Alternative ↓ Follow-up

7. شاشات ووحدات النظام المطبقة في مسار:
- Splash Screen بتصميم انسيابي وشعار مسار.
- Onboarding متعدد المراحل لاختيار النشاط والبيانات المالية الأولية والأهداف.
- Dashboard الذكية: عرض السيولة، الـ Runway، صافي التدفق، الرسم البياني التنبئي لـ 12 شهراً، المخاطر والتوصيات الفورية.
- Simulator (ماذا لو؟): محاكي القرارات المتقدم مع دعم الإدخال باللغة الطبيعية ومقارنة السيناريوهات المتعددة.
- Transactions & Cashflow: تسجيل العمليات وتصنيفها مع الفلترة والتكرار.
- Assets Valuation & Liquidity: تقييم الأصول الرقمية والمادية وتوليد مسارات التسييل الفوري والعائد الإيجاري.
- Bootstrapping Planner: ترشيد الإنفاق وتصنيف التكاليف (أساسية، مهمة، اختيارية) مع بدائل مجانية واقتصادية.
- AI Business Advisor (اسأل مسار): محادثة ذكية مزودة بالسياق المالي اللحظي دون هلوسة.
- Reports & Audit Log: تقارير تنفيذية ومصفوفة مخاطر وسجل تدقيق للامتثال.
- Settings & Privacy: تخصيص العملات والملف الشخصي وتأكيد مسح البيانات بالكامل.
```
